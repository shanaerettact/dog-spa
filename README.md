# Pet Spa & Beauty | 專業毛孩療癒美學

一個現代化的寵物美容 SPA 前端門面網站，提供毛孩舒壓療程、深層護理方案。

## 🌟 特色

- **響應式設計**：完全適配桌面、平板和手機
- **精美動畫**：視差背景、圖片輪播、平滑滾動
- **現代技術棧**：Tailwind CSS、Font Awesome 圖標
- **優化配置**：使用本地 AVIF 圖片格式提升加載速度
- **多語言支持**：台灣繁體中文 (zh-TW)

## 📁 項目結構

```
pet-spa/
├── index.html          # 主頁面
├── 1-11.avif          # 本地圖片資源（AVIF 格式）
├── logo.png           # 商標圖標
├── README.md          # 項目文檔（本文件）

```

## 🎨 頁面部分

1. **導航欄** - 粘性導航，響應式設計
2. **Hero 部分** - 標題、描述、圖片輪播
3. **療程流程** - 5 步驟的舒壓療程展示
4. **服務價目** - 多种方案選項
5. **團隊介紹** - 專業美容師展示
6. **頁腳** - 聯系信息與社交媒體

## 🚀 快速開始

### 方式 1：直接打開 HTML

```bash
# 在瀏覽器中打開文件
open index.html
# 或在 Windows 上
start index.html
```

### 方式 2：使用本地服務器

```bash
# Python 3.x
python -m http.server 8000

# 或使用 Node.js (需先安裝 http-server)
npx http-server
```

訪問 `http://localhost:8000`
